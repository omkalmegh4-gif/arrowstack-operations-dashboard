# Demo script (about 2–3 minutes)

1. Introduce the user problem and intended audience.
2. Show the main responsive interface.
3. Demonstrate the primary happy path.
4. Demonstrate one invalid-input or empty-state scenario.
5. Show keyboard navigation/focus behavior.
6. Explain implementation choices and reusable components.
7. State which checks you actually ran, observed issues, limitations, and next improvements.

Record actual evidence; do not claim measurements or tests that were not performed.
